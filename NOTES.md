# Context for continuing this project from anywhere

**What this is:** An Arabic (RTL) apology web page for my girlfriend, pet name **سمسمتي**.
**Live URL:** https://xabdullashaker.github.io/note/
**Repo:** xAbdullaShaker/note — the whole page is a single file: `index.html`.
**Hosting:** GitHub Pages on the `master` branch. Any commit to `index.html` auto-rebuilds the live page (~1 min).

## The situation (so the tone stays right)
- I tried to gaslight her during an argument, then fell asleep and left her upset. The page owns that honestly — no excuses.
- We're long-distance: she's in Egypt, I'm in Bahrain. Tonight I'm going to the cinema with a friend, and I don't want to leave while she's upset with me.
- Vibe: short, sincere, a little funny — NOT cringe, not wordy.

## What's on the page (in order)
1. Header: big "سمسمتي" + one short line.
2. "الاعتراف" panel — 2 short lines owning the mistake.
3. A gold two-line Arabic verse I provided (already in index.html — keep it as-is).
4. Two Shrek memes embedded as data URIs: sus-Shrek face + staring donkey, with short captions.
5. An embedded TikTok video ("نوح الحنون", a video we used to watch) — TikTok id `7369912400163687697`.
6. Note panel — I'm out at the cinema with a friend tonight, asking her to forgive me first.
7. "سامحتيني؟" — "سامحتك" button + a "لا" button that dodges the finger, then 🤍 confetti.
- Design: dark theme, rose/gold accents, faded tiled-Shrek background, Reem Kufi + Tajawal fonts.

## How to continue (from my phone)
Open Claude Code on the web (claude.ai/code), pick the `xAbdullaShaker/note` repo, tell it to **read NOTES.md**, then give it my change, e.g.:
- "make the verse bigger", "swap the donkey meme", "add a line saying X", "change the background", etc.
It edits `index.html` and commits; the live page updates automatically.
